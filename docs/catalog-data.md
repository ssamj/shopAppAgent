# 教学商品数据

空库初始化包含 32 款女装、232 个颜色尺码规格，价格范围为 169—1199 元。品类包括针织衫、衬衫、半裙、连衣裙、裤装和外套，用于预算、颜色、规格和库存查询练习。

## 数据和图片

- 基础种子数据：`scripts/seed.ts`。
- 增量目录：`data/catalog-20261030.json`，包含 20 款商品和 160 个规格。
- 商品图：`apps/web/public/products/catalog-20261030/`。
- 增量导入实现：`scripts/catalog-data.ts`。

图片为 AI 生成的款式示意，主图展示一种样例颜色。不能从图片推断其他颜色的外观或库存，具体规格以业务查询为准。

## 导入

全新空库执行 `npm run db:init` 时导入基础数据和增量目录。已有基础商品库执行：

```shell
npm run catalog:upgrade
```

事务内更新图片并添加尚不存在的商品与规格。重复执行不会重置库存、占用或重复生成期初入库流水；编号冲突时停止。已有商品价格、订单和业务单据保留。

商城目录最多展示 50 款；模型搜索数量由工具参数控制，不固定推荐数量。

## 验证范围

`npm run verify:catalog` 是升级前后对照脚本，需要准备 `output/catalog-20261030/before.json` 和 `before-business-records.json`，才能比较商品、库存和单据指纹。它不是新克隆后可直接运行的通用冒烟检查。

没有升级前快照时，可通过商城浏览和商品查询核对初始化结果，不应把缺少快照误判为导入失败。
